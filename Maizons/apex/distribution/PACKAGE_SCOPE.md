# Package Scope and Provenance

## Canonical source

`C:\Users\Praxillax\Documents\apps\axxilak\Maizons\apex`

This directory is the only Apex editor source of truth. The contents of `release-candidates\Apex-First-Edition-1.0` are generated delivery artifacts, not a second development branch.

## Included in the customer package

- `index.html` — editable Apex site
- `css\` — local Apex styling
- `js\` — editor modules and handlers
- `icons\` — local theme and brand assets
- `marketing\clock-electrify-instructions.png` — the editor's Edge Electrify visual asset
- `OPEN_APEX.bat`, `START_HERE.md`, `LICENSE.md`, and this manifest

## Intentionally excluded

- source history, QA notes, internal change logs, backups, archives, screenshots, and audit prompts
- other Maisons and older Quill editor copies
- the `engines\apex-editor` implementation copy
- 99CentApps / Last Try storefront files
- payment credentials, payment links, checkout configuration, or a public listing

## Release gate

The package may be inspected and tested locally. Publishing, activating a payment rail, declaring a final price, and replacing a public page each require Timothy's separate outward-facing decision.
