# Apex First Edition 1.0

## Open it

Double-click `OPEN_APEX.bat`, or open `index.html` in a current browser.

An internet connection is required for the included web fonts, Tailwind CDN, the starter photos, and Edge Electrify. No account, subscription, or server is required to edit the included site locally.

## Edit and export

1. Open the page and select **EDIT**.
2. Click a word, picture, button, or container to select it.
3. Change it in the editor panel and choose **SAVE**.
4. Choose **EXPORT HTML** to save the current edit and download a clean `apex-customized.html` file.
5. Keep that exported file beside the included `css`, `icons`, and `marketing` folders. It references those folders.

## Put it online

Upload the complete folder to the host of your choice, then use your exported HTML as the folder's `index.html` if you want it to become the published homepage. The editor stores working edits in this browser's local storage; export is the portable record of those edits.

## Important limits

- This package is a website/editor, not a hosting service.
- Exported work must stay with its included support folders.
- Edge Electrify is an online embedded tool. It needs an internet connection.
- Review `LICENSE.md` before public or client use.
